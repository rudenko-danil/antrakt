# Антракт

Мини-уроки классической музыки на 1–2 минуты: карточки, настоящие записи с Wikimedia Commons, тесты и интервальное повторение (FSRS). Прогресс и статистика времени хранятся на устройстве.

Записи и портреты подгружаются с Wikimedia Commons и Википедии. Если запись недоступна, играет запасной фрагмент из `audio/`, синтезированный по нотам.
